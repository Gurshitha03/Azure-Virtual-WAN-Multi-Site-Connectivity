# Project Abstract

## Azure Virtual WAN Design Study for Multi-Site Connectivity

Azure Virtual WAN is a Microsoft Azure networking service that provides a centralized and scalable approach for connecting multiple sites and Azure Virtual Networks (VNets). As organizations expand across multiple campuses and cloud environments, designing efficient and manageable network connectivity becomes increasingly important.

This project focuses on designing and evaluating an Azure Virtual WAN architecture for multi-site connectivity. The objective is to connect three campuses and two Azure Virtual Networks using Azure Virtual WAN and study how centralized connectivity can simplify network management.

In this project, an Azure Virtual WAN topology is designed to establish connectivity between the participating campuses and Azure VNets. The network architecture and routing requirements are analysed to determine an appropriate connectivity model for the multi-site environment.

The proposed Virtual WAN design is also compared with a traditional hub-and-spoke network architecture. The comparison focuses on connectivity, scalability, routing complexity, centralized management, cost, and suitability for a multi-site enterprise environment.

The study demonstrates how Azure Virtual WAN can provide a scalable and centralized networking approach for connecting multiple sites and VNets. It also highlights important considerations such as Virtual WAN cost for smaller environments and the complexity involved in configuring routing intent.

Overall, this project provides a practical study of Azure Virtual WAN and demonstrates how modern cloud networking services can be used to simplify multi-site connectivity while supporting scalability and centralized network management.
